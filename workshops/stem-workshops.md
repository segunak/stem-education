# STEM Workshops

My list of STEM workshops that are both free and easy for students/learners to access.

- [Build a Video Game](https://arcade.makecode.com/) by Microsoft MakeCode: Create a playable retro game with drag-and-drop code.
- [Battle an AI Bug](https://aka.ms/bug-arena) by Microsoft MakeCode: Program your bug, then test it against other strategies. Ages 8-15. [Educator guide](https://arcade.makecode.com/skillmap/educator-info/bug-arena-info)
- [Train AI for Oceans](https://studio.code.org/courses/oceans/units/1) by Code.org: Train AI to tell fish from trash and help clean up the ocean.
- [Song Maker](https://musiclab.chromeexperiments.com/Song-Maker/) by Google Creative Lab: Click squares to make a tune. Change the tempo and hear how the pattern changes.
- [Quick, Draw!](https://quickdraw.withgoogle.com/) by Google Creative Lab: Draw an object in 20 seconds and see whether AI can recognize it. Drawings join a public research dataset.
- [Flappy Code](https://studio.code.org/flappy/1) by Code.org: Connect code blocks to make a bird flap. Use the first puzzle for a short turn. Ages 10-16. [Educator guide](https://curriculum.code.org/hoc/plugged/3/)
- [Circuit Construction Kit: DC](https://phet.colorado.edu/sims/html/circuit-construction-kit-dc/latest/circuit-construction-kit-dc_en.html) by PhET, University of Colorado Boulder: Connect a battery, wires, and a bulb to make a working circuit. [Educator guide](https://phet.colorado.edu/en/simulations/circuit-construction-kit-dc/teaching-resources) (educator sign-in required).
